# 快速生成发布资料

标准：[发布落地文档](../docs/publishing-standard.md)。后续每次生成发布素材，默认同时生成表情介绍、横幅、封面、聊天图标、赞赏引导语及赞赏两图。

```sh
python -m pip install -r requirements.txt
cp publishing/album-template.json publishing/new-album.json
# 填写新专辑配置并准备图片后执行：
python scripts/build_publication.py publishing/new-album.json --output dist/new-album-release
```

输出目录必须为新目录；再次生成时更换目录名。需要检查跨专辑封面和图标重复时，在同一次命令中传入各专辑配置。

## 固定生成赞赏要素

| 配置字段 | 要求 | 发布包位置 |
| --- | --- | --- |
| `appreciation_prompt` | 5–15 个汉字，标点不计入汉字数；诙谐、与表情相关 | `赞赏/赞赏引导语.txt` |
| `appreciation_guide` | 750 × 560，JPG/GIF/PNG | `赞赏/引导图/` |
| `appreciation_thanks` | 750 × 750，JPG/GIF/PNG | `赞赏/致谢图/` |

两图风格须与表情一致，不出现无关内容；图片默认不叠加文案。单图超过 500 KB 会给出压缩提示。缺失或规格错误均为阻塞项，不能当成完整发布包。配置模板已包含上述三项，不能静默跳过。历史配置未补齐时会显示待补，不影响原始表情文件。

- 每套目录都有单独的 `表情合计.zip`、介绍、CSV 标签、五张配套图、赞赏描述及自动／人工检查清单；缺少的内容列为待补。
- 总合集保持专辑／方案子目录，不混成一套上传。第一版有字与无字为同专辑两个替代方案。
- 退出码 0：自动检查通过，仍需人工审图；退出码 2：存在已列出的缺失／错误，仍输出可检查的交付目录。
- 不同专辑的封面与图标不能相同。新图片由图像生成工具创作，脚本仅校验、汇总和打包，不会伪造缺失图像或自动提交平台。

专辑标题、80 字内介绍、单品 manifest 及各图片路径相对于项目根目录填写，待生成的图片可先填 `null`，但正式完整包不可缺项。
