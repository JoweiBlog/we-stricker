# 快速生成发布资料

标准：[发布落地文档](../docs/publishing-standard.md)。

```sh
python -m pip install -r requirements.txt
python scripts/build_publication.py publishing/v1-captioned.json publishing/v1-no-text.json publishing/v2.json --output dist/publication-20261022
```

输出目录必须为新目录，以避免覆盖此前已确认交付物。再次生成时更换目录名。

- 每套目录有单独的 `表情合计.zip`、介绍、CSV 标签、已提供的横幅／封面／图标及自动／人工检查清单。
- 总合集按专辑／方案保留子目录，不混成一套上传。第一版有字和无字是同专辑两个替代方案。
- 退出码 0：自动检查通过，仍需人工检查；退出码 2：存在已列出的缺失／错误，仍生成可检查的交付目录，不能作为完整发布资料提交。
- 当前 `v2.json` 未绑定第二版专用的横幅、封面和图标，生成时会列为阻塞项；第一版的封面／图标不能作为不同专辑的最终素材。

新专辑复制 JSON 模板，改 `id`（导出目录名）、`album_id`（不同专辑不得相同）、标题、80 字内介绍、单品 manifest 与配套图路径。路径相对于项目根目录；没有的素材填 `null`。脚本不会调用外部服务或上传微信。

需要在同一次调用中提供各专辑配置，才能执行跨专辑封面／图标去重；项目正式发布前应跑全部专辑配置。样例中的介绍为可直接编辑的项目文案，生成图像请使用发布标准内的提示词模板与图像生成工具。
