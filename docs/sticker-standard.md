# 我的刀盾 · 表情包制作基准

记录日期：2026-10-21。依据：用户提供的角色原型稿与表情单品提交要求截图。后续「我的刀盾」表情包以本文件为制作和交付基准。

## 角色基准

- 角色一致性补充（2026-10-22 用户反馈）：后续版本出现脸长、体型拉长、毛发尖硬及爪子过于突出的问题，需回到最初原型与首套概念图的圆润可爱外形。新增表情始终直接引用最初基准，避免以前一张新稿作为唯一参考而逐步改变 IP。
- 外形控制：圆脸、短而宽的口鼻、饱满脸颊、小圆耳、黑亮圆眼、圆滚胸腹、短粗手臂与小爪，毛发柔软细密；表情动作可以改变，脸型、毛色、身体比例与质感保持一致。
- 挑衅的情绪方向：可爱的得意笑、轻轻勾爪，不用凶狠眯眼、长眉弓或夸张的类人手指表现。新修订仅更新制作稿，不覆盖用户已确认的正式文件。
- 以用户提供的多视角原型稿为角色外形依据，保持同一角色在不同表情、动作与视角中的一致性。
- 棕金色柔软毛发、奶油色口鼻及胸腹、圆润矮胖体型、小圆耳、黑亮眼睛、深色鼻子与小爪，延续原稿的写实 3D 毛绒质感。
- 武器沿用原稿短剑及黄铜包边的深灰色盾牌；根据动作需要持握或放在身边，保持造型一致。
- 持盾动作补充（用户修订）：盾牌护在身体另一侧，以前臂及手腕承托、固定，不抓着盾面，也不默认挡在胸腹前。
- 动作画面保持角色比例及脚底定位稳定；为刀尖及盾牌保留安全边距，避免碰到画面下沿或裁切。增加真实过渡姿势，避免单纯重复帧或产生重影的插值。
- 首次生成的九宫格为表情概念展示图；单品交付仍须逐张满足下述规格。

## 图片与动画要求

以下为用户截图中的要求：

| 项目 | 基准 |
| --- | --- |
| 用途 | 在聊天页面中发送的表情图片 |
| 格式 | JPG、PNG 或 GIF |
| 尺寸 | 240 × 240 像素 |
| 大小 | 图片大于 500 KB 将被平台压缩 |
| 动画 | 设置循环播放，节奏流畅、不卡顿 |
| 布局 | 合理安排，每张图片不应有过多留白 |

项目交付约定：单品逐张导出为 240 × 240 像素，尽量控制在 500 KB 以内，以减少平台压缩；500 KB 是截图中的压缩触发阈值，并非截图声明的上传硬性上限。

动画节奏补充（用户确认）：循环播放不要求首尾姿势一致。可在歪头等情绪明确的末帧停顿后重播，不必为衔接而加入回正动作；优先保证动作流畅及情绪表达。

## 单品提交信息

- 每张表情配套填写「含义词」；截图显示输入上限为 4，制作时按不超过 4 个字准备。
- 为每张表情选择 1 或 2 项与内容相符的标签。
- 截图中可选标签：春节、卖萌、其他节假日、潮流热点。

## 交付检查

- 角色外形、毛色与剑盾造型符合原型稿。
- 每个单品为独立文件，格式及尺寸符合要求。
- 检查文件大小，超过 500 KB 时先优化再交付。
- 在 240 × 240 像素下检查表情、动作及文字可辨识度，避免过多留白。
- GIF 检查循环播放、动作连贯性及播放流畅度。
- 准备对应的含义词及 1–2 个匹配标签。

- 用途：表情专辑详情页顶部展示，数量 1 张。

- 避免透明背景，导出为不透明图片。

## 聊天页图标

依据用户 2026-10-22 提供的聊天页图标要求截图：

- PNG 格式，50 × 50 像素；超过 100 KB 将被压缩，项目导出控制在 100 KB 以内。
- 优先选择辨识度高、清晰简洁的角色头部正面图像，不添加装饰元素。
- 必须使用透明背景，避免白底；不添加白色描边，边缘平滑无明显锯齿。
- 不使用正方形边框，避免主体有生硬的直角边缘。
- 布局紧凑，不过多留白，完整保留耳朵等辨识特征。
- 不同表情专辑使用不同图标。

## 表情封面图

依据用户 2026-10-22 提供的封面要求截图：
