# 歪头疑问

- 当前交付：[歪头疑问-停顿版.gif](歪头疑问-停顿版.gif)
- 含义词：疑问
- 标签：卖萌
- 规格：240 × 240 像素，动作段 20 帧/秒，18 个存储帧（相同画面合并停顿），约 382 KB，无限循环，2 秒一轮。
- 动作：托腮歪头、眨眼后停留在歪头疑问姿势，配橙色问号。末帧停顿约 1 秒，再重播；不加入回正动作。
- 角色依据：项目「我的刀盾」原型及首套表情概念图。
- `keyframes.png` 为图像生成工具绘制的六格动画关键帧；`build_gif.py` 使用 FFmpeg 双向运动插值补充中间帧，统一调色板并检查尺寸、循环和文件大小。运行依赖 Pillow 和 FFmpeg。
- `歪头疑问-v1.gif` 为原始低帧率版本，保留用于对比。
