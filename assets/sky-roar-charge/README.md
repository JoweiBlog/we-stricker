# 蓄力仰天大吼

- 当前文件：[蓄力仰天大吼.gif](蓄力仰天大吼.gif)。
- 状态：按用户反馈修订的初稿，尚未纳入正式 V1.0。
- 动作顺序：正常持刀盾 → 屈身低头蓄力 → 起身举刀、盾牌挡在胸腹前 → 仰天张嘴大吼 → 末帧停顿重播。
- 含义词：怒吼；标签：卖萌。
- 规格：240 × 240 像素，3 秒一轮，无限循环，小于 500 KB。
- 使用十二幅绘制姿势；动作转换约每 100 毫秒一个姿势，蓄力与末帧有额外停顿。大幅举刀动作采用原绘制帧，以避免光流插值产生武器和脸部重影。
- `keyframes.png` 为十二格绘制关键帧；`build_gif.py` 使用 Pillow 组装并核验规格。
