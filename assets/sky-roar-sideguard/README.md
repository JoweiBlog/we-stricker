# 蓄力怒吼 · 侧盾修订版

- 当前文件：[蓄力怒吼-直接蓄力版.gif](蓄力怒吼-直接蓄力版.gif)。状态：待用户确认，未纳入正式 V1.0。
- 用户修订要求：盾牌置于身体另一侧而非胸前；以手腕及前臂承托、固定盾牌；刀尖留在画面内；减少画面抖动、改善动作节奏。
- 第一帧直接下蹲蓄力 → 举刀仰天吼叫，盾在身体侧面，最终姿势停留 1.2 秒后重播。
- 原始素材为 16 格绘制姿势。选择 8 个姿势组成最终动画，避免抬头过程倒退；末尾固定同一帧，避免停顿时角色跳变。
- 以深色脚爪定位，统一脚底基线及水平中心；使用同一缩放比例，并为武器保留画面余量。未用光流合成举刀帧。
- 240 × 240 像素，循环时长 1.74 秒，举刀释放阶段每帧 50 毫秒，其余蓄力与停顿帧有延时；文件小于 500 KB。
- 含义词：怒吼；标签：卖萌。
- 使用 `python build_gif.py` 重新组装，需要 Pillow 与 NumPy。

- 最新修订：去掉开头正常站立的三帧，第一帧直接进入蓄力。旧侧盾版保留供对比。
