# 我的刀盾 · 微信静态表情 18 款

从首套及第二套九宫格拆分，保留角色、文字与装饰，每款为独立 PNG。导出遵循用户提供的微信「表情单品」截图规格。

- 数量：18 张；编号 01–09 为首套，10–18 为第二套。
- 尺寸：全部 240 × 240 像素，RGB PNG，白底。
- 大小：每张约 55–74 KB，均小于 500 KB。
- 已逐图检查内容边界，角色、刀盾和文字不串格；按完整内容等比例缩放，四周保留安全边距。
- [全部下载 ZIP](我的刀盾-18款微信静态表情.zip)：包含 18 张 PNG、上传信息 CSV 及校验清单。解压后选择单张 PNG 上传，不上传 ZIP 或预览图。
- [预览](18款预览.jpg)；[含义词与标签](上传信息.csv)；[文件规格与 SHA-256](manifest.json)。

本包是表情单品图片及辅助信息，不包含整套表情专辑上架可能需要的封面、图标或横幅，也不代表已通过平台审核。现有正式 GIF 目录不受影响。

重新导出：`python export.py`，依赖 Pillow、NumPy、SciPy。脚本中的裁切范围按两张原图的实际内容边界设置。
